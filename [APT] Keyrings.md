# Linux: APT Keyrings

APT keyrings (`/etc/apt/keyrings`) in Linux is where administartors store individual GPG public keyring files

* Provides a secure and explicit way to manage keys per repository
* Replaces the deprecated global `apt-key add` method in `/etc/apt/trusted.gpg.d/
* Isolates trust to avoid blindly trusting keys system-wide
